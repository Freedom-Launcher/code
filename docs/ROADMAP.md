# Roadmap

- **M0 — skeleton (done):** workspace, action bus with permission checks, Microsoft sign-in, local profiles, version list with cache, instances, safe settings, CI.
- **M1 — play:** download client/libraries/assets with hash checks and parallelism, Java runtime management, game launch and logs, token refresh, OS keychain, single instance + tray, Shift/tray safe settings.
- **M2 — themes:** theme loader, tokens, screen templates, theme picker, style direction chosen from the mockups.
- **M3 — addons:** isolated addon host, manifest and permission prompt, signing and badges, UI slots, account-provider contract, addon catalog.
- **M4 — mod loaders and content:** Fabric/Quilt/Forge/NeoForge installs, mod browsing, modpack import.
- **M5 — release:** signed installers, auto-updater with signed manifests, startup budget enforced in CI.
